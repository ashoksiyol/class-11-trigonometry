# 📐 Class 11 Mathematics - Trigonometry

A clean, interactive web application providing essential Class 11 Trigonometry formulas, identities, and practice problems.

🚀 **Live Demo:** [Click here to view the app](https://ashoksiyol.github.io/class-11-trigonometry/)

---

## ✨ Features
* **Formula Sheet:** Quick reference for all core trigonometric identities.
* **Interactive UI:** Simple, responsive design built with HTML & CSS.
* **Fast & Lightweight:** Pure frontend implementation.

---

## 🛠️️ Built With
* HTML5
* CSS3
* JavaScript / Python (Flask)
